# 连续体验与可重玩的岛屿

本轮保留首页摄影、版心、静态封面与正式作品入口。小游戏仍是本页的可选实验，不是外部子站的完整服务。

## 会话与展开

每个封面最多挂载一个引擎。收起、切到另一个实验、滚离视口或进入后台只暂停输入、计时与绘图，保留这一页会话里的笔迹、记录和路线。只有“重来”和页面卸载销毁会话；刷新网页会重新开始，不保存到本机文件或远程数据库。

关闭 Motion 只停止装饰动画，不关闭小游戏或抹掉结果。路线的进行动画会停下，用户主动操作仍能查看静态终点。`展开游玩` 使用原生 dialog 的模态顶层，不复制或重新挂载引擎。Esc 返回内嵌尺寸，再次 Esc/收起退出。照片与主页面背景不受影响。

瞄准进行中的暂停或场地改变会将该局标为“中断练习”，保留游玩但不参与连续回合比较。

## 四种玩法的后果

### 用光构图

显影进度是网格估算，不会到 94% 自动补全。可以撤销最后一筆、保留局部暗面并主动定影，定影后在浏览器内生成 PNG。切换取景、收起再打开不会丢失当前页面会话内的作品。

当前有全景、远岸、水光三种取景练习，全部来自仓库内同一张 Pramod Tiwari 月夜摄影。它们不是三张新的摄影作品，也没有接入用户相册。未来增加经授权的独立底片时需要另外整理真实素材。每张最多 100 笔、每笔最多 600 个采样点，防止无界缓存。

### 符文组合

月环留下萤火光团；微风可把光团送到石门；星芒点亮遗迹。月环→微风→星芒得到石门，月环→星芒→微风得到漂移星座。场景会保持到下一次施法，而不只播放后消失。清空法阵不清空三种符文的记录；重来才全部重置。

手绘使用等距重采样与显著几何特征，支持反向及不同大小的圆环、折线和长弧。按钮是明确的辅助施法，不伪装成用户手绘结果。绘画采样保留路径，绘制合并到帧，支持 getCoalescedEvents 的浏览器使用合并前输入，其他浏览器回退到普通指针事件。

### 月落前的旅程

自由漫游仍可任意排序。新模式“赶在月落前”使用公开的虚构规则：第 12 刻月落；旧城花 2 刻取得信和线索；没有线索的山林多花 3 刻，有线索可让下一段少花 1 刻；第 6 刻后到海湾错过渡船，多走 2 刻。

按到访顺序更新山雾、渡船和月亮位置。把灯塔放在最后、能否及时抵达，会产生月落前的回信、守夜人的灯或沿途停靠三个结尾。刻度不代表真实时间、地理距离、交通班次或 AI 生成建议。

### 同组瞄准

完成后可“同组再来”，比较本次页面会话里的上一轮与当前轮。目标种子、场地大小、靶标尺寸、输入方式必须一致，且没有中断、键盘辅助或混合输入，才展示用时与逐靶响应差异。不是跨玩家可信排行榜。

链接参数 `?aim=v1-<uint32>` 只共享目标序列；无效参数忽略。链接保留 Pages 子路径。复制权限不可用时显示可手动复制的只读字段，不申请账户或发送个人成绩。

## 星光与水面

按住拖动才显示第一落点预览，投掷后消失。落水先有短暂接触高光和有上限的水珠，再展开透明透视水圈，远处落点与星体会缩小。完成一轮后出现下一次投掷的可选月光落点挑战。

首屏采用局部 Canvas 2D 透视，不与正文平面高度场硬合并。正文水波使用固定 60Hz 模拟时间步，单次最多追赶三步；高刷新率下不增加模拟速度，长暂停不积压计算。仍限制显示长边 1920、模拟长边 460，并在空闲停止。

## 发布与验证

`public/build-info.json` 在构建时生成，写入实际源码 SHA、构建目标与时间。页面末尾显示对应版本；没有真实源码标识时明确显示未提供，不伪装已同步。Pages 发布与 Sites 发布仍是两条独立路径。

```bash
npm run test:play
npm test
npm run build:pages
npm run test:pages
```

新增固定步长、符文顺序、识别重采样、旅行结局与挑战参数单元测试。Actions 在生产静态产物上继续运行原有星光/四封面、瞄准、暗房/符文/路线测试，并增加会话、展开、PNG、组合结局、同题与跨尺寸回归。旧测试中“离屏清空 DOM”的断言改为“暂停计时且保留内容”，没有删除精度和目标边界检查。

自动化截图与浏览器结果不能替代真实设备的高刷 GPU 帧率测量。本轮不以 CI 软件渲染器的数值承诺用户电脑 FPS。
