# IJ-01 · 会留下后果的小实验

沿用现有月夜摄影、纯深色正文、透明水波与单行封面布局。本次不连接子站业务、不引入账号或新的网页运行时依赖。

## 继续，而不是重新开始

封面引擎在首次打开后保留在本次页面会话中。收起、滚离视口、切换小游戏、切到后台都会暂停工作，返回点击“继续游玩”可接着操作。路线在返回后仍停在暂停位置，需要主动继续；瞄准中断后仍可练习，但不参与连续回合比较。只有“重来”或离开/刷新整个页面才清空本轮。

Motion 开关只控制动态表现，不关闭已打开的游戏。符文保留当前场景，路线可展示静态结尾，瞄准保留统计。首屏星光是一次短暂投掷：离开首屏仍会中止飞行，而非在后台持续运行。

展开采用原生 dialog 的顶层展示，同一 DOM/画布不重挂载。Esc 先回到封面，再按一次收起；模态期间锁定背景滚动并使用浏览器焦点约束。退出恢复入口焦点，静态封面比例和主站左右版心不改变。

## 可以怎么玩

**暗房**：绘画按帧合并，不丢路径端点；可撤销最近四笔、在任意覆盖程度主动定影，再打开继续修改。不再达到 94% 就自动填满。内置仍是已采用的 Pramod Tiwari 月夜摄影。可主动选入三张 JPG/PNG/WebP（每张不超过 12MB、2400 万像素），在浏览器中等比缩到最长边 1600；只使用内存和对象 URL，不上传、不持久化。每张底片保留各自相纸；切换时清空撤销栈，避免积累大幅图像快照。这不是对私人照片岛图库的自动接入。

**符文**：月环聚光 → 微风送光 → 星芒点亮遗迹；月环 → 星芒 → 微风会让符印化为光种子。场景在特效消散后保留。原有三种手绘/辅助共鸣记录继续独立保存。几何识别增加统一尺度与弧长重采样，不调用模型；只识别三种基础笔迹，不声称通用手写识别。

**路线纸**：默认保留自由漫游；可切换“赶在月落之前”。四站之间的抽象旅行与停留时间、取信、山路图、渡船和月落共同决定结尾。规则可展开查看，所有时间都是想象刻度，不是地理距离或真实交通。顺序可以得到按时送信、月落之后或别处停靠三种结尾。关闭動效时得到同样的计算结果，不依赖动画是否跑完。

**六点瞄准**：“同题再试”保留当前种子与六个目标，完成后比较上一局用时与分靶响应。“重来”重新挂载引擎（带挑战链接时仍使用链接种子）。分享只携带 `aim` 无符号整数种子，不上传操作或分数；剪贴板不允许时显示可手动复制的输入框。只有相同种子、规则、场地/靶标尺寸、动效模式、单一指针输入方式且未中断的回合可比较。键盘辅助、混合输入、中断、比赛中尺寸变化都不伪报可比成绩。

**星光**：抓起后显示首次落点预估，飞行不再显示瞄准线。落水依次出现短促接触高光、小水珠、透明水圈，最后一跳可尝试停进月光圈。保留 1–6 次弹跳、点击/键盘替代、静态反馈。独立透视水圈没有冒称已经并入全屏水波高度场。

## 运行和版本

正文 WebGL 高度场固定 60Hz 更新，最大追赶三步；144Hz 显示不再意味着每秒推进 144 次同样的阻尼。空闲/后台不累计待补时间，仍保留原分辨率上限。固定时间步不等于保证任意机器达到 60FPS；实测帧率取决于浏览器和设备。

页面页脚标注内容版本 `IJ-01`；GitHub Actions 发布还附带构建 SHA 前七位。对比 Sites 与 Pages 时请看实际页脚，不能仅凭 GitHub 提交声称 Sites 已发布。没有部署工具的环境不自动发布 Sites。

`app/play/session.ts` 负责可暂停引擎约定，`fixed-step.ts` 负责模拟时钟，`story-model.ts` 负责组合、路线与比较规则。`interactive-journeys.css` 仅处理本次交互增量。

## 云端验证

```bash
npm run test:play
npm test
npm run build:pages
npm run test:pages
```

交互 CI 继续运行原有星光、四封面及精修专项，并新增 `tests/browser-journeys.py` 验证状态保留、展开、部分定影、自选底片、符文组合、多结尾、同题比较、链接复现、中断清理和 320/390/768/1050px 触屏操作。报告记录 CI Chromium 的 rAF 间隔，但不把软件 GPU 环境当作真实用户的硬件 FPS。需要实际浏览器回归通过，不能只依据构建成功判断体验正常。
