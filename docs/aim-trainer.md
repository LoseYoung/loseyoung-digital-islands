# Gridwake · 六点瞄准精修

从岛屿封面的“试一下 / 六点瞄准”启动。默认仍保留完整原封面；新交互不改首屏、正文水波或其他三个封面玩法。新版仅为门户小实验，不是 Gridwake 子站的完整射击游戏。

## 界面和手感

启用后出现低亮度透视网格、分段准星、双环靶标与小型 HUD。普通命中为冷青色，命中中心区为冷金色；空击只留下轻微标记，没有全屏闪白或镜头震动。目标命中后短暂停留反馈，再在新位置显现；不沿路径滑动。每轮随机选择六个有间隔的目标，点击“重来”清空成绩并重新生成。

HUD 显示锁定数量、用时、命中率；下方六格逐个记录普通、中心或键盘命中。最后显示 SECTOR CLEAR 与本轮成绩，不显示虚构排行榜或玩家百分位。

## 统计口径

- 首击后用时：第一次有效命中到第六次命中，包含目标切换间隔；首次瞄准等待不计时。
- 命中率：有效命中 /（有效命中 + 空击），包括首击之前的空击。切换期间与结算之后不接受射击，不额外惩罚双击。
- 平均响应：第 2–6 个目标从显示到命中的平均时间，排除首次等待和目标切换间隔，不代表医学意义的反应时间。
- 中心命中：距离靶心不超过半径 34% 的指针点击。分母只统计指针命中；键盘命中不产生虚假的中心精度，混合操作在结果中标注辅助输入。

## 运行边界

`app/playable-cover.tsx` 为 Gridwake 独立按需加载 `app/play/aim-engine.ts`；其他封面继续使用原引擎。纯计算规则位于 `app/play/aim-model.ts`，局部样式位于 `app/aim-trainer.css`。

未开始与结算后不运行计时器；比赛中 HUD 每 100ms 更新。短暂动画采用 transform / opacity，同时存在的命中特效最多八组。不新增全屏画布、物理引擎、音频或运行时依赖。重来、收起、离屏和后台退出都会清理定时器、延迟任务、事件与动画。

保留原有 Motion 偏好：主动在减少动态效果模式下开始时，玩法与统计仍可用，但不播放准星入场和命中缩放。支持 Tab / Enter；最后一次键盘命中后焦点转到成绩面板。小屏激活态预留足够高度，避免工具栏、HUD、目标和状态文案重叠，不裁切静态封面。
