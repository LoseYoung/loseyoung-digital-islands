# 三座岛屿的封面精修

本轮只更新 Photos Island、Faerie Britain Echoes 和 RoamIsle 的封面小实验。不改六点瞄准、星光打水漂、正文水波、静态封面裁切或页面版心。

## 暗房 / Photos Island

相纸框内显示仓库已有的 Pramod Tiwari 月夜摄影，不使用新增来源不明的照片。细笔和柔光使用不同半径，连续笔划加柔边擦除，快速移动也能连贯显影。笔输入支持压力变化。进度以底片网格覆盖估算，同一区域反复涂抹不会重复计数；达到 94% 后补齐剩余暗层并标记定影。可直接“显影整幅”，原色/银盐影调切换不影响进度。这里的银盐是视觉滤镜，不是真实化学模拟，也不是 AI 按笔迹搜索照片。

## 林间符文 / Faerie Britain Echoes

增加刻度法阵、平滑笔迹、有限时光点与三种共鸣记录。月环以双圈向外扩散，星芒向不同方向散射，微风沿笔迹向林间上升。真实手绘和按钮辅助分别标注为“手绘共鸣”和“辅助唤醒”；辅助施法不伪造绘画水平评分。圆环、折线、长弧仍使用简单几何规则，不是模型识别。三种都唤醒后显示收集完成提示，重来清空本轮记录。

## 路线纸 / RoamIsle

加入示意地形线、方位标记、可拖动地点签、落点提示、已访印记及抵达印章。路线按实际显示的折线长度推进，而不是不同长度的路段各花相同时间。行进可暂停、继续，重新排序会取消旧行程并回到待出发；按钮点击轮换与方向键是拖拽的替代操作。拖出列表范围后取消排序，不误触点击。

四站仍为旧城、山林、海湾、灯塔，地图明确标注为示意。沿途文字是预设文案，不提供真实距离、地理导航、实时天气或 AI 生成结果，也没有调用旅行子站 API。

## 工程边界

`playable-cover.tsx` 分别动态加载 `photo-engine.ts`、`rune-engine.ts`、`route-engine.ts`。六点瞄准继续使用原独立引擎。共用 DOM/画布辅助在 `craft-ui.ts`，纯计算在 `craft-model.ts`，样式限制在 `craft-playgrounds.css` 的三个 data-kind 范围。

未启动不创建实验。照片没有 RAF；符文只在施法后的短时间绘制；路线只在行进时绘制，暂停/完成停止。重来、收起、离屏、后台清理沿用原生命周期。所有引擎使用 AbortController 清理监听器，观察器和 RAF 在销毁时停止。减少动态效果时，主动操作仍有静态反馈，无持续粒子或自动声音。

静态封面仍保持完整等比显示；仅激活态预留操作高度。触屏绘画/拖动只接管局部区域，普通页面滚动不受影响。按钮提供键盘与触屏替代路径；图片加载失败会给出提示。

## 验证

`npm run test:play` 包含底片覆盖率、重复覆盖、模板识别、路线等速、退化路径与最近拖放位置测试。

`tests/browser-crafts.py` 在 CI 的真实 Pages 静态构建上测试：显影/影调/重来、三种符文与手绘标记、拖排/暂停/抵达、收起、不同屏宽、减少动态效果、页面异常及资源错误。继续执行原有星光、四封面和六点瞄准回归。截图与报告位于 `outputs/playgrounds/crafts/`。
